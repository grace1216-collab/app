Onething Worship 安装包

这个文件夹里是一个可以安装到手机桌面的网页 App，iPhone 和安卓都能用，装好后没有网络也能打开。
手机上的 App 只能搜索和查看，不能添加或修改诗歌，所以大家看到的歌库都是同一份。

一、上传（只需要做一次）
把文件夹里的所有文件上传到一个支持 HTTPS 的免费网站空间，例如 GitHub Pages。
上传后会得到一个网址，把它发给团队的同工。

二、安装到手机
iPhone：用 Safari 打开网址，点底部的分享按钮，选「添加到主屏幕」。
安卓：用 Chrome 打开网址，点右上角菜单，选「添加到主屏幕」或「安装应用」。
第一次打开需要网络，之后没有网络也能使用。

三、更新歌库
新增或修改诗歌都由歌库负责人在 Claude 里的 Onething Worship 完成，
改好后重新下载安装包，上传覆盖原来的文件。
大家的手机联网打开 App 时，主页「歌库版本」那一行会显示「正在下载新版…」，
下载好后变成「有新版本，点此更新」，点一下就是新的歌库，不用退出 App。
也可以随时点这一行的「更新」，看看有没有新版本。

四、敬拜歌单
（一）怎么记
投屏时在歌曲页连续停留 1 分钟以上的歌，会按顺序记下来；点进去又马上退出的不算。
同一天的算一场；两首歌之间隔了 3 小时以上，会分成两场。
搜了歌库里没有的歌、转到别的 App 投屏 1 分钟以上，会留一个「待补歌名」的空位，回头在「编辑」里补上。
点「复制歌单」得到的格式是：日期（星期）敬拜用歌，下面每首一行，歌名后面的括号里写出处，可以直接粘贴到微信。

（二）同步给所有人：一次性设置（App 和歌单仓库要在同一个 GitHub 账号下）
1. 在 GitHub 新建一个公开仓库，名字必须是 otw-setlog，勾选「Add a README file」。
2. 打开这个仓库的 Settings → Pages，Source 选「Deploy from a branch」，Branch 选 main，点 Save。
3. 生成钥匙：右上角头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
   名字随意，例如「敬拜歌单」；有效期选最长；Repository access 选「Only select repositories」，只选 otw-setlog；
   Permissions 里把 Contents 设为「Read and write」。生成后复制以 github_pat_ 开头的钥匙，存在安全的地方。
4. 在负责投屏的手机上打开 App →「敬拜歌单」→ 最下面的「同步设置」，粘贴钥匙，点「保存」。
   用 MacBook 投屏时，用浏览器打开同一个 App 网址，同样贴一次钥匙。
其他人的手机不用设置。

（三）注意事项
1. 只有贴了钥匙的设备会记录并上传歌单。其他人的手机只能看和复制，他们翻歌、搜歌都不会被记录。
2. 同一时间只让正在投屏的那台设备记录。贴了钥匙、但这次不投屏的手机，请把「自动记录」关掉，或者聚会中不要用它打开歌曲页；
   轮到自己投屏前再打开「自动记录」。
   同一场中途换人投屏：前一位投完最后一首后回到首页，再切回手机桌面（不用强制关闭 App），App 会马上上传；
   之后这场聚会别再用自己的手机打开歌曲页，或者先关掉「自动记录」。接手的同工照常投屏即可。
   两人投的歌会自动合成同一场，按顺序排好（同一天、前后两段相隔不超过 3 小时）。
3. 钥匙只给自己团队负责投屏的同工，不要给外部团队。钥匙只能改歌单仓库，动不了 App 本身。
4. 外部团队用我们的 App 时，看到的是我们的团队歌单。他们想留自己的歌单，可以在「敬拜歌单」里打开「只记在这台设备」：
   记录只存在他们自己的手机上，不会上传，也不会进我们的歌单。
5. 我们自己哪天用没贴钥匙的手机投屏，也可以先打开「只记在这台设备」记下来，再复制发出去。
   之后这台手机如果贴上钥匙，这些记录会一起上传到团队歌单。
6. 用贴了钥匙的设备删除一场歌单，大家的 App 里也会一起删掉。
7. 歌单仓库是公开的，知道网址的人能看到每场的歌名和时间。
8. 上传要联网。没网时照样记录，有网后会自动补传；别人的手机一般几分钟内就能看到。
9. 钥匙有有效期。到期后「敬拜歌单」页会提示「钥匙无效或已过期」，照第 3 步生成一把新的，在「同步设置」里换上。
10. 手机换了或丢了：在 GitHub 的 Fine-grained tokens 页面把那把钥匙删掉，再给新手机生成一把。
11. Claude 里的 Onething Worship 页面和下载的单文件版不参与同步，歌单只记在那台设备上。

注意
知道网址的人都能打开这个 App，请只在团队内分享。
